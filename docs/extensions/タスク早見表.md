# 追加開発のタスク早見表

追加課題は、**Oracle専用化 → センサーデータ検索・グラフ表示／デバイス管理** の順に段階的に進めます。
この資料では、各機能の名前と作業記号（例： **センサー種別検索（B1）** ）の対応を確認できます。
 **B1などはGitHubのIssue番号ではなく、追加課題内で使う作業記号（Task ID）** です。GitHubのIssue番号は起票時に別途付与されます。

- **GitHubの運用**：[準備ブランチ・Milestone・PR運用](github/準備ブランチ・Milestone・PR運用.md)

## 作業の進め方

1. [追加開発計画](追加開発計画.md)で、開始できる段階を確認する。
2. この一覧で作業名・前提を確認し、該当するIssue原稿を開く。
3. 設計とテスト仕様を確認し、実装から結合確認まで完了させる。
4. 動作する状態をPRで確認してから、次の段階に進む。

※「完了」はコードが書けた時点ではなく、必要なJava・Oracle・REST・画面の動作と試験を確認した状態を指します。
