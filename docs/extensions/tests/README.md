# 追加課題のテスト仕様

各Issueの実装完了後、該当するケースと**既存のMQTT登録・データ一覧の回帰確認**を行います。Javaの処理はJUnit、DB操作は実Oracle、画面はブラウザで確認します。結果はPull Requestに記録してください。
