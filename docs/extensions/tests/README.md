# 追加開発テスト方針・テストケース一覧

> **作業名の確認：** [タスク早見表](../タスク早見表.md)（D0・B1・A1などの記号と担当機能の対応）

## 共通ルール

- **原則1テストIDにつきJUnitの1テストメソッド**（Java側）。CDI管理対象は`@QuarkusTest`を使って`@Inject`でテスト対象を取得する。
- Resourceの単体テストはQuarkus起動中にメソッドを直接呼ぶ。HTTPの実応答は結合試験で確認する。
- JDBCのSQL組立て・パラメータ設定はMockitoで確認し、実Oracleで正しい結果が返るかも確認する。
- ブラウザ／Chart.jsは手動確認。基本的な正常系・境界・未登録・重複などに絞る。
- 各段階で`GET /api/sensors?limit=1`、MQTT受信→Oracle保存、Web一覧の回帰を実施する。
