# 追加開発テスト方針・ケース一覧

## 基本方針

- 1つのテストケースに原則1つのJUnitメソッド。テストIDでIssueを追跡する。
- **CDI管理クラスは`@QuarkusTest`**で動作確認し、対象を`@Inject`で取得する。依存先は`@InjectMock`等で必要に応じて置き換える。
- `SensorResource`／デバイスResourceの単体試験は、**Quarkus起動状態でメソッドを直接呼ぶ**。HTTPレスポンスの確認は実際のHTTPを使う結合試験で行う。
- JDBCのSQLやデータ型・結果の復元はMockitoで単体試験し、実Oracleで登録・SELECTを確認する。
- Chart.js／JavaScriptの画面はブラウザで手動確認。既存Web一覧の回帰確認を忘れない。
- 異常系は必須項目・境界値・不存在・DB障害など基本ケースのみ。認証や過負荷などは対象外。
