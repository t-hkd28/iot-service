# IoTアプリケーション追加開発

現行システムの完成後に、Oracle DBを使って検索・グラフ表示・デバイス管理を追加します。**1つの課題を完成させ、動作を確認してから次に進みます。** すべてを実装する必要はありません。

## どの資料を読むか

1. 下表から自分の課題を開く。
2. Issueにリンクされた**設計書**で仕様を確認する。
3. [テスト仕様](tests/README.md)で結果の確認方法を調べる。

## 共通ルール

- Oracle DBを使用します。CSV用のJavaソースは残しますが、保存先切替は使いません。
- 既存のMQTTメッセージ形式と、条件を指定しない`GET /api/sensors`の動作を維持します。
- 各Issueでは、コード作成だけでなく**テストと画面・API・DBの必要な動作確認**まで行います。
- SQL文とテーブル作成文は、設計書の制約を基に担当者が考えます。
- 認証、設置場所の履歴、複雑な例外処理、ページングは対象外です。
