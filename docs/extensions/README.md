# IoTアプリケーション 追加開発準備資料

> **状態：追加課題の準備稿／未実装。** 現行`master`の動作・仕様を変更する資料ではありません。
>
> 追加課題開始の前提：現行開発の完了、結合試験合格、`master`への統合、`v1.0`タグ付け。

## 確定方針

- Java 21 / Quarkus / Oracle DB / MQTT / HTML・JavaScriptを継続。追加課題で**保存先の選択機能を廃止し、Oracleのみで運用**する。
- `CsvSensorDataRepository`のソースは**削除しない**。CSVへの切替経路とCSV関連の実行時設定は廃止する。
- `SENSOR_DATA`の`SENSOR_ID`は**デバイスIDではない**。デバイスIDとセンサーIDは別物として扱う。
- 設置場所は`SENSOR_LOCATION`マスターテーブルで管理する。ただし設置場所のCRUDまでは作らない。
- 検索条件（種別・ID・期間）はすべて任意、複数条件はAND。グラフは折れ線のみ、Chart.jsを**同梱**する。
- 現行と同じく設計書・テスト仕様書・Issueを訓練生へ渡し、訓練生が実装。複雑なエラー処理や認証は追加しない。
- 各段階で**API、DB、画面の必要な経路が動作し、テスト済み**であること。未完成機能は`master`にマージしない。
