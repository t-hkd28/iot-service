# IoTアプリケーション追加開発準備資料

> 作業記号（D0・B1・A1など）の意味は[タスク早見表](タスク早見表.md)を参照。

> **状態：準備稿・未実装。** 現行`master`の仕様を変更するものではありません。追加課題の設計資料は現行版の完成・結合試験・`v1.0`タグ作成後にマージします。

## 基本方針

- 追加課題の実行時保存先は**Oracle DBのみ**。CSV用のJavaクラスは残し、切替だけ廃止する。
- **検索：** センサー種別検索（B1）、測定日時範囲検索（B2）、設置場所検索（B3）。検索条件はすべて任意指定でAND検索。
- **設置場所検索（B3）** は、デバイスの登録・一覧（C1）とデバイス・センサーの関連付け（C5）の完成後に実装する。関連付け（C5）はC1と測定日時範囲検索（B2）が完成すれば着手できる。
- **グラフ：** 基本折れ線グラフ（A1）、グラフ種別切替（A2）、グラフの測定期間指定（A3）、表とグラフの表示改善（A4）。センサーIDを検索欄へ入力させない。
- デバイスIDとセンサーIDは別。設置場所はマスタ化し、場所のCRUDは作成しない。
- Chart.jsはオフラインで使えるようプロジェクトに同梱。認証・複雑な例外処理・データ移設履歴は扱わない。
- Issueとテスト仕様書を事前に配布し、訓練生が実装。どのTaskもその段階だけで動作可能な状態まで完成させる。
