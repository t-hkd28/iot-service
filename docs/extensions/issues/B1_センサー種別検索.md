# センサー種別検索（B1）

**前提：** Oracle専用化（D0）  
**設計：** [機能仕様](../design/B_センサーデータ検索.md) ／ **テスト：** [B1-01～03](../tests/README.md)

## 目的

種別で測定データを絞り込めるようにする。

## 作業

API・Service・Repositoryに任意の種別条件を追加し、Web画面で種別を選べるようにする。検索用SQLは自分で設計する。

## 完成条件

種別指定時は一致するデータのみ、未指定なら従来の一覧が表示される。

対応するテストを実施し、結果をPRに記録してレビューを受けること。
