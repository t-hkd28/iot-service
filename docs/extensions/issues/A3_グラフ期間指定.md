# グラフの測定期間指定（A3）

> **作業名の確認：** [タスク早見表](../タスク早見表.md)（D0・B1・A1などの記号と担当機能の対応）
- **種別：** enhancement / area:graph
- **概算：** 3人時（2～4人時）
- **前提Task：** グラフ種別切替（A2）、測定日時範囲検索（B2）
- **詳細設計：** [グラフ表示](../design/A_グラフ表示.md)
- **テストID：** A3-01～A3-02（[テスト一覧](../tests/README.md)）

## 目的

グラフに測定期間の指定を追加し、既存の検索APIの`from`・`to`を再利用して折れ線を更新する。

## 実装作業

- グラフの期間入力欄を表示し、入力値を既存API呼出しに渡す。
- 指定期間の取得結果でグラフを更新し、0件時はデータなしとする。
- 同じ種別の異なるセンサーIDの値を1本の線に混在させない。

## 完成条件

- [ ] 開始・終了を指定したとき期間内のデータだけが描画される。
- [ ] 種別と期間を併用できる。
- [ ] 不正な範囲の入力が適切に拒否される。
- [ ] ブラウザで実動作・回帰テストを行い、PRに記録する。
