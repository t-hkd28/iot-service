# センサー関連付け（C5）

**前提：** デバイス登録・一覧（C1）、測定日時範囲検索（B2）  
**設計：** [機能仕様](../design/C_デバイス管理.md) ／ **テスト：** [C5-01～04](../tests/README.md)

## 目的

デバイスにセンサーIDを割り当て、デバイス別の測定値を表示できるようにする。

## 作業

割当テーブル・割当／解除／一覧APIと画面、デバイス別データ取得APIを作る。必要なSQLは自分で設計する。

## 完成条件

1台への複数割当・割当解除・重複割当防止・デバイス別データ表示ができる。

対応するテストを実施し、結果をPRに記録してレビューを受けること。
