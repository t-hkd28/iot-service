# 測定日時範囲検索（B2）

> **作業名の確認：** [タスク早見表](../タスク早見表.md)（D0・B1・A1などの記号と担当機能の対応）
- **種別：** enhancement / area:search
- **概算：** 12人時（10～15人時）
- **前提Task：** センサー種別検索（B1）
- **詳細設計：** [センサーデータ検索](../design/B_センサーデータ検索.md)
- **テストID：** B2-01～B2-05（[テスト一覧](../tests/README.md)）

## 目的

測定期間でセンサーデータを絞り込み、種別・期間を任意にAND指定して一覧表示できるようにする。

## 実装作業

- `GET /api/sensors`に任意の`from`・`to`を追加する。開始以上、終了未満とし、片側だけの指定も認める。
- Filter・Service・Repository・Oracle SQLへ日時条件を追加する。ソート後に件数制限する。
- Web画面に日時の入力欄を追加。未指定で従来動作、日時逆転はエラーとする。
- CDI対象のJUnit・MockitoとOracle・ブラウザの結合確認。

## 完成条件

- [ ] 開始のみ／終了のみ／両方で検索できる。
- [ ] センサー種別と日時範囲を組み合わせてAND検索できる。
- [ ] 不正な日時・開始が終了以上の指定を拒否できる。
- [ ] 条件未指定の`GET /api/sensors?limit=100`を壊していない。
- [ ] テスト記録をPRに記載し、レビュー後にマージ可能。
