# 測定日時範囲検索（B2）

**前提：** センサー種別検索（B1）  
**設計：** [機能仕様](../design/B_センサーデータ検索.md) ／ **テスト：** [B2-01～05](../tests/README.md)

## 目的

期間と種別を任意に組み合わせて測定データを検索できるようにする。

## 作業

開始・終了日時をAPI・Repository・画面に追加する。必要なSQLは自分で設計する。

## 完成条件

開始のみ・終了のみ・両方・種別とのAND検索が動き、逆転した期間は拒否される。

対応するテストを実施し、結果をPRに記録してレビューを受けること。
