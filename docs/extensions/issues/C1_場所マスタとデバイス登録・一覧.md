# デバイス登録・一覧（C1）

**前提：** Oracle専用化（D0）  
**設計：** [機能仕様](../design/C_デバイス管理.md) ／ **テスト：** [C1-01～03](../tests/README.md)

## 目的

場所を選んでデバイスを登録し、一覧で確認できるようにする。

## 作業

設置場所・デバイスのテーブル、場所一覧・デバイス一覧・登録APIと画面を作る。テーブル作成文と操作SQLは自分で設計する。

## 完成条件

場所を選んで登録したデバイスが一覧に現れ、重複IDは登録されない。

対応するテストを実施し、結果をPRに記録してレビューを受けること。
