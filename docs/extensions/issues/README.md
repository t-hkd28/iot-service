## 運用上の注意

1. **APIだけ／DBだけのマージを完成としない**。機能が使える縦切りを完成させてからマージする。
2. 訓練生の担当者は追加開始時の習熟度・希望で再決定。
3. 見積もりは訓練生の評価ではなく計画の目安。
4. Issueに対応するテストIDをPRへ記録し、完成後にMilestoneを閉じる。
