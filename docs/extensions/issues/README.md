## 使い方

1. 完成した前提Taskを確認する。
2. Taskの設計・テストIDを確認し、Issueとして起票する。
3. 対応Milestoneへ登録し、`Estimate (h)`を設定する。
4. JUnit・実Oracle・ブラウザの実施結果をPRに記録する。
5. 訓練期間が不足するなら次のTaskを始めず、最後の動作確認済み状態を完成成果とする。
