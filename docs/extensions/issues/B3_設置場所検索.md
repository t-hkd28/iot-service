# 設置場所検索（B3）

**前提：** 測定日時範囲検索（B2）、センサー関連付け（C5）  
**設計：** [機能仕様](../design/B_センサーデータ検索.md) ／ **テスト：** [B3-01～05](../tests/README.md)

## 目的

現在の設置場所で測定データを検索できるようにする。

## 作業

場所一覧APIから選択肢を表示し、locationIdを任意条件としてAPI・Repository・画面に追加する。テーブルの関係を利用するSQLは自分で設計する。

## 完成条件

場所単独・種別・期間とのAND検索ができ、場所を省略した場合は未割当データも取得できる。

対応するテストを実施し、結果をPRに記録してレビューを受けること。
