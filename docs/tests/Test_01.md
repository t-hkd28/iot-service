# Test_01：Repository共通検証

**実施方法**：JUnit。実際のCSVやDBを使用せず、保存・取得の結果を記録するテスト用の部品を利用する。

**判定**：以下の期待結果がすべて満たされればOK。実施できない場合は理由を記録する。

| テストID | 操作・条件 | 期待結果 |
|---|---|---|
| T01-01 | 正常なセンサーデータ1件を保存する。識別子は「TRAIN-01」、種別は温度、値は23.5、単位は「C」、測定日時は2026年11月20日10時とする。 | 保存先へ同じ内容が1回だけ渡される。 |
| T01-02 | センサーデータそのものを指定せずに保存を試みる。 | 不正な入力として例外が発生し、保存先には渡されない。 |
| T01-03 | センサー識別子を「未設定」「空文字」「空白のみ」に変えて、それぞれ保存を試みる。 | いずれも不正な入力として例外が発生し、保存処理は実行されない。 |
| T01-04 | センサーの種別を未設定にして保存を試みる。 | 不正な入力として例外が発生し、保存処理は実行されない。 |
| T01-05 | 単位を「未設定」「空文字」「空白のみ」に変えて、それぞれ保存を試みる。 | いずれも不正な入力として例外が発生し、保存処理は実行されない。 |
| T01-06 | 測定日時を未設定にして保存を試みる。 | 不正な入力として例外が発生し、保存処理は実行されない。 |
| T01-07 | 取得結果が空になるよう準備し、取得件数の下限「1」と上限「1000」をそれぞれ指定する。 | どちらも正常に受け付けられ、指定した件数が取得処理に渡される。 |
| T01-08 | 取得件数に範囲外の「0」と「1001」をそれぞれ指定する。 | どちらも不正な入力として例外が発生し、取得処理は実行されない。 |
| T01-09 | データ1件が入った、後から変更可能な一覧を取得元に用意する。取得後、一覧への要素追加と取得元の一覧変更を試す。 | 取得した一覧には要素を追加できず、取得元の一覧を変更しても取得済みの一覧は変わらない。 |
