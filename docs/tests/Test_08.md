# Test_08：Web API通信モジュール

**実施方法**：ブラウザを使う手動試験。開発者ツールの「ネットワーク」で送信内容と応答を確かめる。

**判定**：以下の期待結果がすべて満たされればOK。実施できない場合は理由を記録する。

| テストID | 操作・条件 | 期待結果 |
|---|---|---|
| T08-01 | 保存済みデータを2件用意し、画面から取得件数「2」で検索する。 | 2件の取得要求が送信され、サーバーからJSON配列が返り、画面にエラーが表示されない。 |
| T08-02 | 教員の指示のもと、APIがサーバーエラーを返す状態で検索する。 | 通信結果がHTTP 500となり、画面でエラーを確認できる。 |
