# Test_06：RESTリソースの処理

**実施方法**：`@QuarkusTest`＋Mockito。Quarkus/CDIからResourceを取得し、そのメソッドを**直接呼び出す**。Serviceはモック化し、HTTPリクエスト送信やHTTPレスポンスの検証は行わない。

**判定**：以下の期待結果がすべて満たされればOK。実施できない場合は理由を記録する。

| テストID | 操作・条件 | 期待結果 |
|---|---|---|
| T06-01 | サービスが1件のデータを返す条件を準備し、取得件数「1」で検索する。 | サービスに1件の取得が依頼され、準備したデータが返される。 |
| T06-02 | 取得件数の上限「1000」を指定する。 | 不正な件数として扱われず、サービスに1000件の取得が依頼される。 |
| T06-03 | 取得件数として「0」を指定する。 | `ClientErrorException` が発生し、範囲外であることが分かるメッセージが含まれる。データ取得処理は行われない。 |
| T06-04 | 取得件数として「1001」を指定する。 | `ClientErrorException` が発生し、データ取得処理は行われない。 |
| T06-05 | 【結合試験】HTTPで正常取得、不正な件数の指定、保存先エラーの3条件を確認する。 | 正常時はHTTP 200とデータ一覧、不正件数はHTTP 400、保存先の失敗はHTTP 500が返る。単体試験では合格と判定しない。 |
