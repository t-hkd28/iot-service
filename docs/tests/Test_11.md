# Test_11：Oracleテーブル作成SQL

**実施方法**：実際のOracleに接続して手動で確認する。既存の訓練データを誤って消さないようにする。

**判定**：以下の期待結果がすべて満たされればOK。実施できない場合は理由を記録する。

| テストID | 操作・条件 | 期待結果 |
|---|---|---|
| T11-01 | 教員が指定したスキーマで、作成したSQLファイルを1回実行する。 | センサーデータを保存するテーブルがSQLエラーなく作成される。 |
| T11-02 | 作成したテーブルの列の一覧を確認する。 | 自動採番用ID、センサー識別子50文字、種別30文字、測定値は小数4桁まで、単位20文字、測定日時を保存でき、必要な項目が必須となっている。 |
| T11-03 | 作成したテーブルの制約を確認する。 | 自動採番用IDが主キーに設定されている。 |
| T11-04 | 試験用のセンサーデータを1件登録し、読み出した後に削除する。 | IDを指定しなくても自動採番され、登録した各項目が正しく読み出せる。 |
| T11-05 | 既にテーブルがある場合の再実行について確認する。 | 再実行ではエラーになる場合があるため、教員の指示なくテーブルの削除・再作成を行わない。 |
