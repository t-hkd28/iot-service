# Test_03：JDBCからの最新データ取得

**実施方法**：JUnit＋Mockito。取得データの有無やDB操作失敗をテスト用の結果により再現する。

**判定**：以下の期待結果がすべて満たされればOK。実施できない場合は理由を記録する。

| テストID | 操作・条件 | 期待結果 |
|---|---|---|
| T03-01 | 測定日時の異なる2件を、新しいデータから順に返す条件を用意し、2件の取得を要求する。 | 指定件数以内の2件が正しく変換される。検索SQLには新しい日時を優先し、同日時では後から登録されたものを優先する並び順と、件数制限がある。 |
| T03-02 | 検索結果が0件になる条件を用意し、5件の取得を要求する。 | 空の一覧が返され、異常終了しない。 |
| T03-03 | 検索SQLを準備するときにDBエラーが起きる条件を用意する。 | データアクセスの失敗を表す例外が発生し、元のDBエラー情報が保持される。 |
| T03-04 | 検索でデータを正常に取得する。 | 検索結果、SQL実行に使った資源、DB接続がすべて解放される。 |
| T03-05 | 【結合試験】Oracleに同じ測定日時のデータを2件、順番に登録して最新順に取得する。 | 後から登録したデータが先に返る。モックだけでは実際のSQLの並び順は保証できない。 |
