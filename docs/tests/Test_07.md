# Test_07：MQTT受信と非同期登録

**実施方法**：実際のMQTT BrokerとQuarkusを使用する結合試験。JUnit・Mockitoは使用しない。

**判定**：以下の期待結果がすべて満たされればOK。実施できない場合は理由を記録する。

| テストID | 操作・条件 | 期待結果 |
|---|---|---|
| T07-01 | MQTTを有効、保存先をCSVとし、他の訓練生と重複しない接続識別子・トピックを設定して起動する。正常なJSONを1件送信する。 | 一定時間後にCSVへ該当データが記録され、保存エラーが発生していない。 |
| T07-02 | JSONとして正しくない文字列を1件送信し、続けて正常なJSONを1件送信する。 | 不正なデータは保存されずエラーが確認できる。その後の正常データは保存される。 |
| T07-03 | MQTT Brokerを停止した状態で、MQTT受信を有効にしてアプリケーションを起動する。 | Brokerに接続できないことが確認でき、接続成功と誤認しない。 |
| T07-04 | Brokerに正常接続した状態からアプリケーションを終了する。 | 終了処理によりBrokerとの接続が切断される。終了直前の未処理データの保存は保証しない。 |
| T07-05 | 区別できる正常データを続けて3件送信する。 | 順に保存処理が行われる。通信方式による重複配送そのものの防止は今回の対象外。 |
