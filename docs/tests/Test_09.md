# Test_09：Web画面表示・入力検証

**実施方法**：ブラウザを使う手動試験。必要に応じて開発者ツールの「ネットワーク」「要素」を使用する。

**判定**：以下の期待結果がすべて満たされればOK。実施できない場合は理由を記録する。

| テストID | 操作・条件 | 期待結果 |
|---|---|---|
| T09-01 | APIを起動した状態で、初めてトップ画面を開く。 | 初期件数100件で取得要求が1回送信される。 |
| T09-02 | 取得件数に「0」「1001」「1.5」をそれぞれ入力し、取得ボタンを押す。 | どの場合も入力エラーが表示され、不正な値の取得要求は送信されない。 |
| T09-03 | 保存データを2件用意し、取得件数「2」で表示する。 | 件数が2と表示され、表にデータが2行表示される。 |
| T09-04 | データを含まないCSVを保存先として、画面を表示する。 | 取得件数は0と表示され、データがないことを示す案内が出る。 |
| T09-05 | 画面表示後にアプリケーションを停止し、再取得する。 | 以前の取得結果が消去され、件数は0となり、通信エラーの案内が出る。 |
| T09-06 | ブラウザの通信速度を低速に設定してデータを取得する。 | 取得中はボタンが使用できず、通信が終わると再び使用できる。 |
| T09-07 | テスト専用データに、HTMLタグの形をした文字列を含めて表示する。 | タグとして解釈・装飾されず、入力した文字列がそのまま表示される。 |
