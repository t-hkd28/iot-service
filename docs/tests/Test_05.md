# Test_05：設定に応じたRepository生成

**実施方法**：`@QuarkusTest`。保存方式ごとにテストプロファイルを使い分け、CDIで生成・注入されたRepositoryの種類を確認する。JDBCを選択しても実SQLは実行しない。

**判定**：以下の期待結果がすべて満たされればOK。実施できない場合は理由を記録する。

| テストID | 操作・条件 | 期待結果 |
