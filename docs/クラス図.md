# 詳細版
```mermaid
classDiagram
direction LR

namespace runtime {
  class SensorPipeline {
    -String brokerUrl
    -String topic
    -String clientId
    -int qos
    -SensorDataService service
    -MqttReceiver receiver
    +onStart(StartupEvent) void
    +onStop(ShutdownEvent) void
  }
}

namespace mqtt {
  class MqttReceiver {
    -String brokerUrl
    -String topic
    -String clientId
    -int qos
    -MqttClient client
    -SensorDataService service
    -ExecutorService executor
    +MqttReceiver(...)
    +start() void
    +stop() void
  }
}

namespace resource {
  class SensorResource {
    -SensorDataService service
    +SensorResource(SensorDataService)
    +getSensors(int limit) Response
  }
}

namespace service {
  class SensorDataService {
    -SensorDataRepository repository
    -ObjectMapper objectMapper
    +SensorDataService(...)
    +register(String json) void
    +findAll(int limit) List
  }
}

namespace repository {
  class SensorDataRepository {
    <<interface>>
    +save(SensorData) void
    +findAll(int limit) List
  }

  class AbstractSensorDataRepository {
    <<abstract>>
    +save(SensorData) void
    +findAll(int limit) List
    #doSave(SensorData) void
    #doFindAll(int limit) List
  }

  class CsvSensorDataRepository {
    -Path path
    +CsvSensorDataRepository(Path)
    #doSave(SensorData) void
    #doFindAll(int limit) List
  }

  class JdbcSensorDataRepository {
    -DataSource dataSource
    +JdbcSensorDataRepository(DataSource)
    #doSave(SensorData) void
    #doFindAll(int limit) List
  }

  class RepositoryProducer {
    -StorageType storageType
    -String csvPath
    -Instance~DataSource~ dataSource
    +createRepository() SensorDataRepository
  }

  class RepositoryException {
    <<exception>>
    +RepositoryException(String, Throwable)
  }
}

namespace model {
  class SensorData {
    <<record>>
    +String sensorId
    +SensorType sensorType
    +double value
    +String unit
    +LocalDateTime measuredAt
  }

  class SensorType {
    <<enumeration>>
    TEMPERATURE
    HUMIDITY
    ILLUMINANCE
  }
}

SensorPipeline --> MqttReceiver : 生成・起動・停止
SensorPipeline --> SensorDataService : DI
MqttReceiver --> SensorDataService : register()
SensorResource --> SensorDataService : findAll()

SensorDataService --> SensorDataRepository : 保存・取得
SensorDataService ..> SensorData : 生成・返却

AbstractSensorDataRepository ..|> SensorDataRepository
CsvSensorDataRepository --|> AbstractSensorDataRepository
JdbcSensorDataRepository --|> AbstractSensorDataRepository

RepositoryProducer ..> SensorDataRepository : 生成
RepositoryProducer ..> CsvSensorDataRepository : 生成
RepositoryProducer ..> JdbcSensorDataRepository : 生成

CsvSensorDataRepository ..> SensorData : 保存・復元
JdbcSensorDataRepository ..> SensorData : 保存・復元

SensorData --> SensorType : センサー種別
SensorDataRepository ..> RepositoryException : 例外
```
