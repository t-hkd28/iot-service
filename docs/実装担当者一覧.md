# IoTシステム開発実習 ― 実装担当者一覧

> **目的**：作業の難易度と必要な技術を比較して担当者を決め、チーム全員で共有する。  
> **記入方法**：担当決定後、右端の「担当者」欄に氏名を記入する。難易度は教材としての目安であり、個人の能力評価ではない。  
> **対象**：`iot-service` ベースプロジェクト。課題番号（01～11）は教材内の管理番号であり、GitHubが発行するIssue番号とは異なる。

## 実装対象と担当者

難易度：★☆☆（比較的易しい）／★★☆（標準）／★★★（難しい）

| 課題 | 機能・実装対象 | 対象ファイル（`src/main`配下） | 必要な技術分野 | 難易度 | 標準工数（人時） | 担当者 |

| 02 | Oracle DBへのデータ登録（INSERT） | `JdbcSensorDataRepository.java` | Java、SQL、JDBC、例外・リソース管理、Mockito | ★★★ | 11 | 横須賀 |
| 03 | Oracle DBからの最新データ取得（SELECT） | `JdbcSensorDataRepository.java` | Java、SQL、JDBC、ResultSet、Mockito | ★★★ | 12 | |
