# IoTセンサー情報管理システム（訓練生用ベースプロジェクト）

このリポジトリは**チーム開発実習用の未完成プロジェクト**です。各自がGitHubの担当Issueに従って実装・テストし、Pull Request（PR）で変更を統合します。

> **初めて作業する人は、以下の 1 → 6 の順に進めてください。** ソースコード内の `TODO` は、担当Issueに従って実装する箇所です。

## 1. GitHubに参加し、Eclipseへ取り込む

1. 指導員からのGitHubリポジトリ招待を承認する。
2. **[チーム開発の運用ルール・操作手順](docs/GitHubチーム開発_運用ルール・操作手順.md#4-初回準備各メンバー1回のみ)**に従い、Eclipse（EGit）でリポジトリを**Clone**する。
3. Eclipseで`pom.xml`を含むプロジェクトをMavenプロジェクトとして取り込む。
4. JDK 21が設定されていることを確認する。

> 指導員が用意したリポジトリを共同で利用します。新しいリポジトリの作成や`git init`は不要です。

## 2. 作るものと設計資料を確認する

1. **[システム概要書](docs/design/システム概要書.md)**：何を作るかを確認する。
2. **[方式設計書](docs/design/方式設計書.md)**：どのような仕組みで作るかを確認する。
3. **[設計書の案内](docs/design/README.md)**：自分の担当機能に必要な外部・内部設計書を選ぶ。
4. **[完成版のJavaDoc](docs/apidocs/index.html)**：必要に応じてクラスやメソッドの仕様を調べる（ブラウザで開く）。

設計資料は**完成時に実現する仕様**を示します。現時点で実装済みかどうかは、下記「5. 担当Issueに着手する」とソースコードの`TODO`を確認してください。

## 3. 開発・実行環境を準備する

**[開発環境の設定と動作確認](docs/開発環境・動作確認.md)** を参照してください。次の順序で進めます。

1. JDK 21 / Mavenが利用できるか確認する。
2. EclipseでQuarkus起動用の**Mavenビルド実行構成**を作成する。
3. 必要な環境変数（保存方式、CSVパス、DB接続先、MQTT接続先など）を設定する。
4. **最初はMQTTを無効にして、CSV方式で確認する。** Oracle DB・MQTT Brokerは担当機能の確認時に準備する。

> **配布版の注意**：`RepositoryProducer`は初期状態でCSVを固定選択します。`APP_STORAGE_TYPE=JDBC`を指定しても、切替処理の実装前はCSVが使われます。

## 4. 初期状態を確認する

- Eclipseの実行構成から`quarkus:dev`を実行する（操作は[開発環境の設定と動作確認](docs/開発環境・動作確認.md#2-eclipseから起動する)）。
- ブラウザで `http://localhost:8080/` を開く。ただし、配布版はREST API・画面処理等が未完成のため、**完成版どおりにデータ取得できなくても正常です**。
- CSVの基本的な保存・取得は実装済みです。単体確認方法は[開発環境の設定と動作確認](docs/開発環境・動作確認.md#4-初期状態と確認できる範囲)を参照してください。

## 5. 担当Issueに着手する

1. GitHubの**Issues**で自分の担当Issueと完成条件を確認する。
2. [設計書の案内](docs/design/README.md#担当別の参照先)から必要な資料を開く。
3. [テストの進め方と仕様書一覧](docs/tests/README.md)で、単体試験と結合試験の実施時期・方法を確認する。
4. [GitHub運用手順](docs/GitHubチーム開発_運用ルール・操作手順.md#5-日常の作業手順issueごとに繰り返す)に従い、`master`からIssue専用ブランチを作る。
5. Eclipseで実装・**担当する単体試験** → Commit → Push → GitHubでPR作成 → レビュー → マージする。MQTT・SQL・JavaScriptの確認方法は各テスト仕様書を参照する。

**`master`には直接Pushしないでください。** テスト結果はIssueまたはPRに記録します。実装順序は担当Issueと指導員の指示を優先してください。

## 6. 結合試験・完成確認

機能別の実装が統合されたら、実環境での結合試験を行います。まず[テスト仕様書（Test_10：全体結合）](docs/tests/Test_10.md)に沿って、MQTT受信 → CSV/Oracle保存 → REST API → Web画面を確認します。

NG時の対応や終了時の手順は[GitHub運用手順](docs/GitHubチーム開発_運用ルール・操作手順.md#9-結合試験プロジェクト完了)を参照してください。
